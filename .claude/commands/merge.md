방금 논의한 내용을 반영해서 현재 다루고 있는 챕터(`chapters/**/*.qmd`)의 관련 섹션을 기존 문체를 유지하며 재작성(병합)해줘. 완료 후 git commit 하나 생성해줘. (규칙: CLAUDE.md의 "콘텐츠 수정 규칙" 참고)

커밋 후에는 수정한 챕터를 렌더링해서 에러 여부만 확인해줘. (OS에 맞는 쪽을 쓰면 돼)

- Windows: `.\scripts\render-check.ps1 <수정한 챕터 파일>`
- macOS/Linux: `./scripts/render-check.sh <수정한 챕터 파일>`

빌드 에러가 없으면 그걸로 끝 — 스크린샷, 브라우저 리로드 확인, 다른 챕터 렌더링 등 추가 테스트는 진행하지 마.
